# BBellWeb

Subscription marketing site and AI Site Studio for **bbellweb.info**.

**Stack:** Next.js 15 (Node.js), Stripe, OpenAI. No third-party app hosts required.

```bash
cd platform
npm install
cp .env.example .env.local
npm run dev
```

See [platform/README.md](./platform/README.md) for deploy, Stripe, and DNS.
